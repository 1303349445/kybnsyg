# 🎭 AI 赛博算卦 · 无日志占卜

> *“没日志没代码？神仙也得随机蒙 —— 专治技术提问只甩一句话的玄学工具”*

这是一个 **WebGL 风格、完全图形化** 的幽默占卜 H5 页面。当你面对一个“什么都没提供”的技术提问时，可以用它**随机生成一卦**，用赛博朋克+AI 大模型幻觉的口吻，给出既荒诞又带点真实建议的答案。

---

## ✨ 特色

- 🔮 **纯 Canvas / WebGL 渲染** – 无 DOM 卡片、无圆角、无毛玻璃，采用硬边斜切、速度线、噪点等复古/科幻 UI。
- 🤖 **AI 氛围编程卦象** – 内置 16+ 条卦辞，每一条都围绕“没日志、没堆栈、靠 AI 瞎蒙”创作，幽默且扎心。
- ⚡ **硬朗动画** – 摇卦时触发速度线爆发、闪白、面板抖动，拒绝温吞淡入淡出。
- 📱 **完全自适应** – 固定 1280×720 画布，自动居中缩放，手机电脑都能玩。
- 🧙 **一键起卦** – 点击锋利多边形按钮，立即获得全新卦象（emoji + 卦名 + 等级 + 描述 + 技术小贴士）。
